# steerform

Steer HTML/Markdown form fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/steerform/

## Install / run

```bash
git clone https://github.com/theworker02/steerform.git
cd steerform
node src/cli.js
node --test
```
